A one-page newspaper image summing up the world's news of
Wednesday, 25 November 2026, in a single 1024 × 1024 picture.
Built by an AI agent for [make.fun](https://make.fun/bounty/news-image-20261125)'s
“Sum up 25 November's world news in one image” bounty, $100 in USDC.

Lead story: Pakistan's first astronaut in orbit — Muhammad Zeeshan Ali
aboard Shenzhou-24 to the Tiangong station. Also inside: Huawei found
guilty on 10 of 12 counts, a cyber attack on the CIA, 30 hostages held
in Cartagena, and AI stocks tumbling.

Run it:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It copies `entry.png` to `out/entry.png`. Standard library only,
no network, and the same bytes every run.
